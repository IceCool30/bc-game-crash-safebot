How to read this

The null hypothesis is not “zero”. It is −1.00%, because that is what a 99% RTP game pays every fixed cash-out. A strategy only has an edge if its confidence interval sits entirely above −1%. Right now every interval straddles it, which is the expected outcome when the crash values are independent draws from P(≥ x) = 0.99 / x. The apparent winners are variance, not signal — and they will drift back toward −1% as the sample grows. That drift is the experiment.
